# Intake Forms — AI Consulting

Common fields (business name, contact name/email/phone) apply to every form
below; not repeated per service. Consulting deliverables are written
reports/recommendations — scoped and delivered async, same as every other
category; no discovery call required.

## 1. AI Readiness Assessments
- Business overview (free text)
- Current tools / tech stack (write-in list)
- Pain points (free text)
- Goals for using AI
- **Uploads:** any relevant supporting docs
- Turnaround / Budget range
- Delivery: written readiness report

## 2. AI Strategy Consulting
- Business goals (free text)
- Current AI usage, if any
- Constraints: budget, timeline, compliance (write-in)
- Turnaround / Budget range
- Delivery: written strategy document

## 3. AI Tool Selection
- Use case description
- Budget range for tooling
- Must-have features (write-in list)
- Current stack / systems to integrate with
- Turnaround / Budget range
- Delivery: tool comparison + recommendation

## 4. AI Implementation
- Which tool/solution is being implemented
- Current systems it needs to work with
- Timeline / target go-live date
- Turnaround / Budget range
- Delivery: implemented solution + setup summary

## 5. AI Workflow Design
- **Uploads:** current process flow, if documented (or free-text description)
- Goals for the redesigned workflow
- Constraints (tools, budget, compliance)
- Turnaround / Budget range
- Delivery: workflow design document

## 6. AI Training for Employees
- Team size / roles to train
- Current skill level (beginner / intermediate / advanced)
- Topics needed (write-in list)
- Format: video / written guide / async course
- Turnaround / Budget range
- Delivery: training materials

## 7. AI Process Optimization
- Process description (free text)
- Current pain points / metrics (write-in)
- Goals for optimization
- Turnaround / Budget range
- Delivery: optimization report + recommendations

## 8. Custom AI Solution Design
- Problem statement (free text)
- Current systems involved
- Constraints
- Success criteria
- Turnaround / Budget range
- Delivery: solution design document
