# Intake Forms — Administrative Services

Common fields (business name, contact name/email/phone) apply to every form
below; not repeated per service.

## 1. AI Data Entry
- **Uploads:** source data (spreadsheet, images, PDFs)
- Destination system: spreadsheet / CRM / database (name it)
- Field mapping (which source fields go to which destination fields)
- Turnaround / Budget range
- Delivery: completed data set in destination format

## 2. Spreadsheet Cleanup
- **Uploads:** spreadsheet to clean
- Issues to fix (check all): duplicates, formatting, missing data, broken formulas
- Desired final structure (write-in, or "match existing")
- Turnaround / Budget range
- Delivery: cleaned spreadsheet

## 3. CRM Data Management
- CRM platform + access method (login shared, or export/import only)
- Task needed (check all): dedupe, import, cleanup, field updates
- **Uploads:** data source file, if importing
- Turnaround / Budget range
- Delivery: updated CRM + change summary

## 4. Calendar Management
- Calendar platform + access method
- Scheduling rules / preferences (write-in)
- Recurring tasks needed (write-in list)
- Turnaround / Budget range
- Delivery: configured calendar + rules summary doc

## 5. Email Organization
- Email platform + access method
- Desired folder/label scheme
- Rules for auto-sorting (write-in)
- Turnaround / Budget range
- Delivery: organized inbox + rules summary doc

## 6. Meeting Notes
- **Uploads:** recording or transcript
- Format needed: summary / action items / full notes
- Distribution list (who receives the notes)
- Turnaround / Budget range
- Delivery: notes document

## 7. Meeting Summaries
- **Uploads:** recording or transcript
- Summary depth: one-paragraph / detailed
- Distribution list
- Turnaround / Budget range
- Delivery: summary document

## 8. Task Management
- Current tool used (Asana / Trello / Sheets / other)
- Source of tasks (email, docs, verbal notes — **Uploads** if applicable)
- Desired structure (projects, tags, priority levels)
- Turnaround / Budget range
- Delivery: populated task management setup

## 9. File Organization
- Access to drive/folder (link + permissions)
- Current pain points (write-in)
- Desired folder structure (write-in, or "recommend one")
- Turnaround / Budget range
- Delivery: reorganized files + structure map

## 10. Digital Filing Systems
- Approximate volume of files
- Categories needed (write-in list)
- Platform: Google Drive / Dropbox / SharePoint / other
- Turnaround / Budget range
- Delivery: filing system set up + structure map
