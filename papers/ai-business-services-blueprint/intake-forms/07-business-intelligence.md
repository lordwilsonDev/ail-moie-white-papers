# Intake Forms — Business Intelligence

Common fields (business name, contact name/email/phone) apply to every form
below; not repeated per service.

## 1. Business Knowledge Assistant
- **Uploads:** source documents
- Platform: internal search tool / chatbot
- Intended users
- Turnaround / Budget range
- Delivery: deployed assistant + content source list

## 2. Internal AI Search
- Data sources to index (Drive, Notion, Slack, other — check all)
- Access method (permissions/export)
- Turnaround / Budget range
- Delivery: deployed search tool

## 3. SOP Assistant
- **Uploads:** existing SOPs, if any
- Processes to document (write-in list)
- Format needed: doc / chatbot / video-script
- Turnaround / Budget range
- Delivery: SOP document set

## 4. Training Assistant
- **Uploads:** training materials
- Format needed: quiz / course / chatbot
- Audience
- Turnaround / Budget range
- Delivery: training materials, deployed

## 5. Company Wiki AI
- **Uploads:** existing wiki/docs
- Platform (Notion / Confluence / other)
- Structure needed (write-in)
- Turnaround / Budget range
- Delivery: populated wiki

## 6. Executive Dashboard Assistant
- Data sources (write-in list)
- KPIs to track
- Platform: Sheets / Looker / Power BI / other
- Turnaround / Budget range
- Delivery: configured dashboard

## 7. Report Generation
- Data source(s)
- Report frequency
- **Uploads:** format/template, if one exists
- Turnaround / Budget range
- Delivery: generated report(s)

## 8. Data Analysis
- **Uploads:** dataset
- Questions to answer (write-in list)
- Output format: report / spreadsheet / dashboard
- Turnaround / Budget range
- Delivery: analysis output

## 9. KPI Tracking
- KPIs to track (write-in list)
- Data sources
- Reporting cadence
- Dashboard platform
- Turnaround / Budget range
- Delivery: configured tracking + first report
