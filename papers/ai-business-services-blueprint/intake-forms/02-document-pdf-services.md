# Intake Forms — Document & PDF Services

Common fields (business name, contact name/email/phone) apply to every form
below; not repeated per service.

## 1. PDF Consultant
- **Uploads:** sample PDF(s) representing the problem
- Describe the problem / desired outcome (free text)
- Turnaround / Budget range
- Delivery: written recommendation + next-step options

## 2. PDF Summarization
- **Uploads:** PDF(s) to summarize
- Summary format: bullet points / paragraph / executive summary
- Intended audience
- Turnaround / Budget range
- Delivery: summary document, same file format as source

## 3. PDF Search Assistant
- **Uploads:** PDF set, or link to a shared folder
- Example queries users will ask
- Delivery format: searchable index / chatbot / spreadsheet lookup
- Turnaround / Budget range
- Delivery: deployed search tool + usage instructions

## 4. Contract Review Assistant
- **Uploads:** contract(s) to review
- Review focus (check all): risk clauses, obligations, key dates, compliance
- Output preference: redlines / summary memo / both
- Jurisdiction / governing law
- Turnaround / Budget range
- Delivery: annotated contract + summary memo

## 5. Policy & Procedure Assistant
- **Uploads:** existing policies (if any)
- Gaps or new policies needed (write-in list)
- Turnaround / Budget range
- Delivery: policy document set

## 6. Employee Handbook AI
- **Uploads:** current handbook or company background info
- Sections needed (write-in list)
- State / country (for compliance references)
- Turnaround / Budget range
- Delivery: draft handbook document

## 7. Document Digitization
- **Uploads:** scans, or shipping/drop-off instructions for physical docs
- Output format needed: PDF / Word / searchable PDF
- Naming and organization scheme preference
- Turnaround / Budget range
- Delivery: digitized files, organized per spec

## 8. OCR Data Extraction
- **Uploads:** scanned documents / images
- Data fields to extract (write-in list)
- Output format: CSV / Excel / JSON
- Turnaround / Budget range
- Delivery: structured data file

## 9. Invoice Processing
- **Uploads:** invoices, or link to a folder
- Data fields needed (check all): vendor, amount, date, PO number, line items
- Output format
- Accounting system to import into (if any)
- Turnaround / Budget range
- Delivery: structured invoice data file, import-ready if applicable

## 10. Receipt Processing
- **Uploads:** receipts, or link to a folder
- Expense categories to sort into (write-in list, or "use standard")
- Output format
- Turnaround / Budget range
- Delivery: categorized expense report

## 11. Form Automation
- **Uploads:** existing paper or PDF form
- Desired output: fillable PDF / web form / Google Form
- Integration needed on submit (email / Sheets / CRM / none)
- Turnaround / Budget range
- Delivery: automated form + test submission

## 12. Knowledge Base Creation
- **Uploads:** source materials (docs, SOPs, FAQs, etc.)
- Target platform (Notion / Confluence / website / other)
- Audience: internal / customer-facing
- Turnaround / Budget range
- Delivery: populated knowledge base + structure outline
