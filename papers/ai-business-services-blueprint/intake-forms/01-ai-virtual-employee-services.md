# Intake Forms — AI Virtual Employee Services

Common fields (business name, contact name/email/phone) apply to every form
below; not repeated per service. See `README.md` for the shared rule: form
alone must be enough to scope and price — no call.

## 1. AI Phone Receptionist
- Industry / business type
- Business hours and timezone
- Phone number: forward existing number, or provision new number?
- Call greeting: use standard greeting, or write-in / **Uploads:** script
- Common caller intents (checkboxes: sales, support, scheduling, billing, other)
- When AI can't resolve a call: voicemail / forward to number / text owner
- **Uploads:** FAQ document for Q&A handling
- Turnaround: Standard / Rush
- Budget range
- Delivery: live number + config summary doc

## 2. AI Call Answering
- Business hours and timezone
- Phone number to answer for
- **Uploads:** call handling script (or "use standard")
- Escalation number for calls the AI can't handle
- Turnaround / Budget range
- Delivery: live call-answering config + summary doc

## 3. AI Appointment Scheduling
- Calendar system in use (Google Calendar / Calendly / other — name it)
- Availability rules (days/hours, buffer time between appointments)
- Appointment types and durations
- Confirmation/reminder channel: SMS / email / both
- Cancellation policy text
- Turnaround / Budget range
- Delivery: connected scheduling flow + confirmation of test booking

## 4. AI Lead Qualification
- Lead source(s): web form, ads, referral, other
- Qualifying questions — write-in or **Uploads:** existing script
- Scoring criteria (budget, timeline, authority, need — check all that apply)
- CRM to push qualified leads to
- Turnaround / Budget range
- Delivery: qualification flow + sample scored lead output

## 5. AI Customer Service
- **Uploads:** product/service documentation
- Common support topics (write-in list)
- Tone/voice guidelines (write-in or **Uploads:** brand voice doc)
- Escalation path for unresolved issues
- Hours of coverage needed
- Turnaround / Budget range
- Delivery: configured assistant + escalation summary

## 6. AI Live Chat Assistant
- Website URL
- Pages where the chat widget should appear
- **Uploads:** knowledge base / help docs
- Tone guidelines
- Handoff rule: when to route to a human, and to whom
- Turnaround / Budget range
- Delivery: installed widget + test transcript

## 7. AI Email Assistant
- Inbox to manage (shared inbox address)
- Categories of email handled (write-in list)
- Draft-for-review vs. auto-send preference
- **Uploads:** signature / reply templates
- Escalation rule (what gets flagged to a human)
- Turnaround / Budget range
- Delivery: configured inbox rules + sample drafted replies

## 8. AI SMS Assistant
- Phone number to use for SMS
- Use case: reminders / support / marketing (opt-in confirmed) — check all
- **Uploads:** message templates
- Confirmation that opt-out / compliance language is included
- Turnaround / Budget range
- Delivery: live SMS flow + sample message log

## 9. AI Voice Assistant
- Voice persona preference (tone, gender-neutral option available)
- Use case: inbound IVR / outbound calls / both
- **Uploads:** call script
- Integration needed (CRM / calendar / none)
- Turnaround / Budget range
- Delivery: configured voice flow + sample call recording

## 10. AI FAQ Assistant
- **Uploads:** source documents for FAQ content
- Website URL, if embedding on-site
- Delivery format: chat widget / standalone page / Slack bot
- Turnaround / Budget range
- Delivery: deployed FAQ assistant + content source list
