# Intake Forms — Business Automation

Common fields (business name, contact name/email/phone) apply to every form
below; not repeated per service.

## 1. Workflow Automation
- Describe the current manual process, step by step (free text)
- Tools involved in the process (write-in list)
- Trigger event (what starts the process)
- Desired outcome / end state
- Turnaround / Budget range
- Delivery: automated workflow + process diagram

## 2. CRM Automation
- CRM platform
- Automation goal: lead routing / follow-up / data sync / other
- Trigger conditions (write-in)
- Turnaround / Budget range
- Delivery: configured automation + test run summary

## 3. Invoice Automation
- Invoicing tool used
- Trigger for invoice creation (write-in)
- Data source (order system, spreadsheet, CRM)
- Delivery method for invoices: email / portal / other
- Turnaround / Budget range
- Delivery: automated invoicing flow + sample invoice

## 4. Proposal Automation
- **Uploads:** proposal template (if one exists)
- Data inputs needed per proposal (write-in list)
- Delivery format: PDF / DocuSign / other
- Turnaround / Budget range
- Delivery: automated proposal generator + sample output

## 5. Estimate Generation
- **Uploads:** pricing sheet / rules
- Inputs needed per estimate (write-in list)
- Output format
- Turnaround / Budget range
- Delivery: estimate generator + sample output

## 6. Quote Generation
- Pricing logic (write-in, or **Uploads:** pricing sheet)
- Inputs needed per quote
- Output format and integration needed
- Turnaround / Budget range
- Delivery: quote generator + sample output

## 7. Contract Generation
- **Uploads:** contract template(s)
- Variable fields to populate per contract (write-in list)
- E-signature platform (if any)
- Turnaround / Budget range
- Delivery: contract generator + sample output

## 8. Purchase Order Automation
- **Uploads:** PO template
- Trigger conditions for PO creation
- Approval workflow (who approves, in what order)
- Turnaround / Budget range
- Delivery: automated PO flow + sample output

## 9. Customer Follow-Up Automation
- Follow-up triggers (check all): post-purchase, no-response, renewal, other
- **Uploads:** message templates
- Channel: email / SMS / both
- Turnaround / Budget range
- Delivery: automated follow-up flow + sample sequence

## 10. Reminder Systems
- Reminder types needed (write-in list)
- Trigger conditions
- Channel: email / SMS / both
- Recipients
- Turnaround / Budget range
- Delivery: configured reminder system + test run
