# Intake Forms — Customer Experience

Common fields (business name, contact name/email/phone) apply to every form
below; not repeated per service.

## 1. Customer Support Bots
- Platform: website / app / both
- **Uploads:** knowledge base
- Tone / brand voice
- Escalation rule (when to route to a human)
- Turnaround / Budget range
- Delivery: deployed bot + test transcript

## 2. Help Desk Automation
- Ticketing platform used
- Common ticket types (write-in list)
- Routing rules
- Turnaround / Budget range
- Delivery: configured automation + test run

## 3. Ticket Routing
- Ticketing platform used
- Team structure / routing rules (write-in)
- Priority criteria
- Turnaround / Budget range
- Delivery: configured routing rules + test run

## 4. Review Response Assistant
- Review platforms (check all: Google, Yelp, Facebook, other)
- Brand voice / tone
- Response guidelines (write-in, or **Uploads:** examples)
- Turnaround / Budget range
- Delivery: response templates + sample responses

## 5. Customer Feedback Analysis
- **Uploads:** feedback data (surveys, reviews, support tickets)
- Analysis goal (write-in)
- Output format: report / dashboard / spreadsheet
- Turnaround / Budget range
- Delivery: analysis report

## 6. Loyalty Program Automation
- Program rules (write-in)
- Platform used
- Trigger events for rewards
- Turnaround / Budget range
- Delivery: configured automation + test run
